# Вакансия 3 — Project Manager (аутсорс / интегратор)

Компания: Example Integrator  
Формат: remote / office  
Грейд: Middle+  

## Требования
- Ведение проектов заказной разработки  
- Оценка, пресейл, статусы, приёмка  
- Jira, MS Project  
- Коммуникации с заказчиком  

## Обязанности
- Полный цикл проекта  
- Бюджет, сроки, риски  
- Отчётность и эскалации

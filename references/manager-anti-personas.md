# Anti-personas менеджера (сигналы в резюме)

Рынок перестаёт покупать harness management. Фиксировать, когда CV *читается* как один из типов. Только диагноз + цитаты, не rewrite.

## 1. Project administrator
**Текст:** Jira-гигиена, статусы, созвоны, пинги дедлайнов, отчёты.  
**Сигналы:** «вёл Jira/Confluence», «собирал статусы», «напоминал о сроках» без delivery outcome.  
**Почему убивает:** дорогая ops-обвязка, автоматизируется.

## 2. Project proxy (телефон)
**Текст:** customer ↔ eng без своих решений; «коммуникации», «синхронизация», «эскалации».  
**Сигналы:** нет продукта/домена/tech; outcomes у «команды/заказчика».  
**Почему:** latency + distortion; не видно judgment.

## 3. Ritual agile PM
**Текст:** ceremonies as achievements — daily, retro, planning, grooming.  
**Сигналы:** «внедрил Scrum» без before/after по flow/качеству/бизнесу.  
**Почему:** cargo cult; налог на скорость.

## 4. Unimmersed delivery manager
**Текст:** владеет сроками/E2E, но без инженерной реальности.  
**Сигналы:** давление на даты; нет MR/docs/risks в системе; блокеры только «организационные».  
**Почему:** pressure without understanding.

## 5. Manager-router
**Текст:** «привлёк аналитика / техлида / продакта / CTO».  
**Сигналы:** фасилитация чужой работы; ноль своих решений.  
**Почему:** «зачем этот человек в цепочке?»

## 6. General management without domain
**Текст:** «управляю людьми и процессами» по несвязанным отраслям.  
**Сигналы:** title soup; нет industry vocabulary; «оптимизировал процессы» без объекта.  
**Почему:** нужен T-shaped; pure generalist в хвосте.

## Использование в score
На каждую персону: **CLEAR / PARTIAL / NONE** + 1–3 цитаты.  
CLEAR на 2+ → системный issue «reads as harness/admin PM».

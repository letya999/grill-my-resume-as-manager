# Role families (manager track)

Disambiguate who the resume claims to be. Contradictory families in one CV are a primary reject reason.

## Families

| Family | Core job | Typical vocabulary |
|--------|----------|-------------------|
| **Project Manager (classic)** | one/many projects: scope, plan, risk, budget, acceptance | сроки, бюджет, риски, Устав, приёмка, заказчик |
| **Delivery Manager** | flow of product delivery, speed/quality of teams | throughput, WIP, lead time, release train, end-to-end |
| **Tech / Technical PM** | delivery + technical depth | architecture, API, migration, platform, MR, SLA |
| **Product Manager / PO** | problem, outcome, discovery, prioritization | roadmap, discovery, metrics, JTBD, experiment |
| **Program / PMO** | multi-project portfolio, standards, governance | portfolio, stage-gate, PMO, compliance |
| **Scrum Master / Agile Coach** | team system health, coaching | facilitation, maturity, impediments (not delivery owner) |
| **Admin / coordinator** | task tracking, org glue | Jira admin, minutes, reminders — **not target for this skill's success bar** |

## Conflict patterns
- PM desired title + admin bullets → anti-persona #1
- Product title + pure schedule bullets → family mismatch
- Delivery title + zero engineering or flow metrics → anti-persona #4
- "Head of / Director" title + IC-scale scope → grade inflation flag
- Sales + PM hybrid without framing → "sales who helped PM" read

## Grade signals (rough)
| Grade | Evidence patterns |
|-------|-------------------|
| Junior / Assistant | ceremonies, task moves, learning, no owned budget |
| Middle | owns project outcomes, small-mid team, some metrics |
| Senior | multi-stream, material scope (team/budget/risk), domain depth, decisions |
| Lead / Head | org design, hiring, P&L or portfolio, sets system for others |

## Output requirement
State: **claimed family**, **claimed grade**, **family the text actually supports**, **mismatch yes/no** with quotes.

# Семейства ролей (manager track)

Развести, **кем** CV претендует быть. Противоречия — частая причина reject.

## Семейства

| Family | Суть | Словарь |
|--------|------|---------|
| **Project Manager** | scope, план, риск, бюджет, приёмка | сроки, бюджет, риски, Устав, заказчик |
| **Delivery Manager** | поток поставки, скорость/качество команд | throughput, WIP, lead time, release |
| **Tech / Technical PM** | delivery + tech depth | architecture, API, migration, SLA, MR |
| **Product Manager / PO** | problem, outcome, discovery | roadmap, discovery, JTBD, experiment |
| **Program / PMO** | портфель, стандарты | portfolio, stage-gate, PMO |
| **Scrum Master / Agile Coach** | health системы команды | facilitation, impediments |
| **Admin / coordinator** | task tracking, glue | Jira admin, minutes — **не** success bar скилла |

## Конфликты
- Desired PM + admin bullets → anti-persona #1  
- Product title + pure schedule → family mismatch  
- Delivery title + zero eng/flow metrics → #4  
- Head/Director + IC-scale → grade inflation  
- Sales + PM без framing → «sales who helped PM»

## Грейд (грубо)
| Grade | Паттерны |
|-------|----------|
| Junior / Assistant | ceremonies, task moves, нет owned budget |
| Middle | project outcomes, mid team, часть метрик |
| Senior | multi-stream, material scope, domain, decisions |
| Lead / Head | org design, hiring, P&L/portfolio, система для других |

## Output
**claimed family**, **claimed grade**, **что текст реально поддерживает**, **mismatch yes/no** + цитаты.

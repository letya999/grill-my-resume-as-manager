# Калибровка XYZ для PM / Delivery / Product

## Правило
Достижение существует только с измеримым результатом: цифра, артефакт, интервал или явный «до/после». Иначе — процесс или scope, не achievement.

## XYZ
- **X** — сильный глагол + объект
- **Y** — что изменилось
- **Z** — метрика / артефакт / окно времени

Предпочтение: **XYZ** (не STAR). STAR ок, только если X+Y+Z явны.

## Типы строк

| Тип | Смысл | XYZ? |
|-----|--------|------|
| achievement | outcome, причинённый кандидатом | PASS / WEAK / FAIL |
| process | активность без outcome | не PASS |
| scope-statement | факт карьеры (команда, title, переход) | отдельно; не achievement |
| noise | soft / filler | флаг |

## Калибровка

| Строка | Вердикт | Почему |
|--------|---------|--------|
| «Управлял командой 8 разработчиков» | FAIL | только X; headcount = scope |
| «Координировал миграцию, релиз 2 нед → 2 дня» | PASS | X+Y+Z |
| «Работал в команде, где MAU 100k→500k» | FAIL | метрика не приписана кандидату |
| «Увеличил конверсию на 15%» | WEAK | нет базы и окна |
| «Провёл CustDev» | WEAK/process | процесс без outcome |
| «Способствовал утроению выручки» | FAIL | вклад не атрибутирован |
| «Перешёл из Android в PM» | SCOPE | не XYZ |
| «Суперсила — разруливать кризисы» | NOISE | маркетинг |
| «Расширил команду 5→18» | WEAK/scope | рост без бизнес-эффекта |
| «Настроил Jira для прозрачности» | process/noise | tool hygiene |
| «Провёл ретро, повысил вовлечённость» | WEAK/fail | soft, без меры |
| «Вёл дейли/груминги» | process | ritual anti-persona |
| «TTM −25% внедрением Scrum» | WEAK | нужны baseline/окно/что в flow |
| «Продукты в топ-15 интеграторе, оборот 40 млрд» | FAIL as achievement | vanity работодателя |
| «€1.5M ARR, 35 enterprise» | WEAK без ownership | PASS только при явном личном P&L/GTM/closed-won |

## Тесты attribution
1. Кандидат — причинная сила (не «команда/компания»)?
2. Единица релевантна роли (скорость, качество, деньги, риск, adoption)?
3. Впечатлит *этого* hiring manager (product vs platform vs enterprise delivery)?
4. Это vanity работодателя (оборот холдинга, top-N vendor)?
5. Защитит ли метрику на 10-минутном grill без hand-waving?

## Жёсткие правила
- Размер команды сам по себе — **не** achievement.
- «Качество +N%» без определения quality → WEAK.
- Soft-стеки («ответственный, коммуникабельный») — noise.
- Относительные lifts на крошечной базе ($6k/mo ×3) — absolute context или WEAK для senior bar.

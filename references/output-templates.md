# Шаблоны output

Язык отчёта = язык резюме.

## Общие правила
- Вердикт с **дословной цитатой**.  
- **Direction** = вид правки. **Нет** rewritten bullets / sample «как лучше».  
- No sugar. TL;DR первым.

---

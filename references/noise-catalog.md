# Noise and filler catalog (manager resumes)

Mark as **шум** when present without an attached artifact or business outcome. Quote each hit.

## Soft markers (classic)
- коммуникабельность / communication skills
- ответственность / responsible
- стрессоустойчивость
- командный игрок / team player
- проактивность / results-oriented
- "суперсила", "магия", motivational slogans

## Process water (PM-specific)
- настроил прозрачность в Jira/Confluence/Notion without Z
- проводил daily / retro / planning / grooming / review as the achievement
- "улучшил коммуникации стейкхолдеров" without decision or metric
- "вёл документацию" as standalone value
- "эскалировал риски" without mitigation outcome
- demo/presentation to leadership without decision taken

## Skills-list water
- "Управление проектами", "Работа в команде", "Тайм-менеджмент" as skills
- Kitchen-sink methodology list (Agile, Scrum, Kanban, Waterfall, SAFe, PRINCE2…) with no proof in Experience
- Soft skills dominating the skills block (>15–20% of items)

## Format / ATS noise
- multi-column fancy layouts, icons, skill bars
- age/DOB, salary expectation on CV (cuts conversion both ways)
- confidential / NDA-only work with zero substitute label
- desired role "Project Manager **или** администратор проектов" (conflicting titles)
- empty About-me hobbies HR does not use
- **export/OCR garbage**: random spaces inside words (`Г изатуллин`, `T elegram`), broken hyphenation, empty `•` bullets, "page break" slide dumps inside CV
- presentation/case-deck pages mixed into the resume without a portfolio link

## How to report
For each noise hit: line id, quote, class (soft / process-water / skills-water / format), one-line impact on reader ("reads as admin", "no hook for ATS", "wastes 10s scan").

## Fix direction language (allowed)
- "Drop or convert this line — needs business Z, not tool hygiene."
- "Move soft claim out; only keep if tied to a named conflict/outcome."
- Do **not** supply the rewritten bullet text.

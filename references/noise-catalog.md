# Каталог шума (менеджерские резюме)

Помечать **шум**, если нет артефакта или бизнес-outcome. Каждое попадание — с цитатой.

## Soft-маркеры
коммуникабельность · ответственность · стрессоустойчивость · командный игрок · проактивность · results-oriented · «суперсила» / мотивационные слоганы

## Process water (PM)
- прозрачность в Jira/Confluence/Notion без Z  
- daily / retro / planning / grooming как achievement  
- «улучшил коммуникации стейкхолдеров» без решения/метрики  
- «вёл документацию» как ценность само по себе  
- «эскалировал риски» без mitigation outcome  
- demo руководству без принятого решения  

## Skills water
- «Управление проектами», «Работа в команде», «Тайм-менеджмент»  
- kitchen-sink методологий без proof в Experience  
- soft &gt;15–20% блока skills  

## Format / ATS
- колонки, иконки, skill bars  
- возраст/ДР, вилка ЗП на CV  
- confidential без domain hint  
- title soup «PM **или** администратор»  
- хобби в About без work mechanism  
- **export/OCR**: пробелы внутри слов, пустые `•`, slide-deck внутри CV  
- presentation pages без portfolio link  

## Directions (можно)
- «Убрать или перевести в business Z — не tool hygiene.»  
- «Soft только если привязан к named conflict/outcome.»  
- **Не** подставлять готовый буллет.
